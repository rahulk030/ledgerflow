# Contributing

This is primarily a portfolio repository, but the code is structured for normal pull-request based development.

1. Create a focused branch from `main`.
2. Keep changes small enough to review in one pass.
3. Add or update tests when business behavior changes.
4. Run the relevant type checks, tests, and build locally.
5. Use a clear commit message that explains the intent of the change.

Please avoid drive-by formatting changes in the same commit as functional work.
